# Рабочие листы — прототип

Интерактивный прототип по макетам Figma и спецификации «Функциональность „Рабочие листы“».

Подробное описание архитектуры и полный текст всех промптов — в файле `docs/SERVICE.md`.

## Запуск

```bash
npm install
npm run dev
```

http://localhost:5173/

## Что работает

### 1. Создание
- Генерация ИИ: предмет, параллель, тема (обязательно), количество 1–15, пожелания ≤500
- Расширенные: план заданий (типы + описания), «Сгенерировать план», сложность, вводная часть
- Создание вручную → сразу в редактор

### 2. Редактирование
- Страницы: добавить / переключать
- Блоки заданий: краткий ответ, один/несколько вариантов, пропуски, сопоставление, группировка, упорядочивание, развёрнутый ответ
- Инструменты: текст, поле ответа, таблица, разрыв страницы
- Редактирование, порядок ↑↓, удаление
- «Сгенерировать задание» — добавить одно задание без полной перегенерации
- Настройки: показывать сложность / ответы

### 3. Печать
- Размещение (один лист / ответы отдельно)
- Число копий, ориентация
- Сохранить (localStorage) и Распечатать (`window.print`)

Панель **«Экраны макета»** внизу справа — быстрый переход по состояниям.
